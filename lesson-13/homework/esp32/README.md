# Модуль 2.5 — Таймери

ESP32-S3 керує витяжним вентилятором через GPIO21:

- цикл запуску — 1 година;
- час роботи — 15 хвилин;
- one-shot hardware timer відміряє одразу весь інтервал;
- `loop()` не керує часом і використовується лише для логування;
- `delay()` відсутній;
- захист від повторного запуску забезпечує стан `running_`;
- LED на GPIO21 дублює стан вентилятора.

Послідовність alarm:

```text
OFF 3600 с → ON 900 с → OFF 2700 с → повтор
```

Щосекундного interrupt і програмного лічильника часу немає.

## Підключення

```text
ESP32 GPIO21 ── IN реле або драйвера
ESP32 GND ───── GND реле або драйвера
```

Двигун не можна підключати безпосередньо до GPIO. Потрібне реле або
транзисторний драйвер із зовнішнім живленням. Для active-low реле змінити
`Config::FanActiveHigh` на `false`.

## Збірка

Production timing:

```bash
pio run -e esp32s3
pio run -e esp32s3 -t upload
```

Debug timing — цикл 20 секунд, робота 5 секунд:

```bash
pio run -e esp32s3_debug
pio run -e esp32s3_debug -t upload
```
