# Embedded Homework

Домашні роботи з embedded-розробки на ESP32-S3, C++ та PlatformIO.

## Структура

| Урок | Тема | Завдання |
| --- | --- | --- |
| 01 | Основи електроніки | Теорія |
| 02 | Світлодіоди та резистори | Розрахунки, експерименти |
| 03 | ESP32-S3 | [Task 01](lesson-03/task-01), [Task 02](lesson-03/task-02) |
| 04 | GPIO | [Поліцейська мигалка](lesson-04/task-01), [Керування LED кнопкою](lesson-04/task-02), [Домашнє завдання](lesson-04/homework) |

Практичні завдання зберігаються як окремі PlatformIO-проєкти або локальні бібліотеки, які підключаються до головного проєкту для збірки та прошивки.

## Плата

- Freenove ESP32-S3 WROOM
- Arduino framework
