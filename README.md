# Embedded Homework

Домашні роботи з embedded-розробки на ESP32-S3, C++ та PlatformIO.

## Структура

| Урок | Тема | Завдання |
| --- | --- | --- |
| 01 | Основи електроніки | Теорія |
| 02 | Світлодіоди та резистори | Розрахунки, експерименти |
| 03 | ESP32-S3 | [Task 01](lesson-03/task-01), [Task 02](lesson-03/task-02) |
| 04 | GPIO | [Task 01](lesson-04/task-01), [Task 02](lesson-04/task-02) |

Кожне практичне завдання — окремий PlatformIO-проєкт. Відкривайте папку потрібного завдання у VS Code або запускайте PlatformIO з неї.

## Плата

- Freenove ESP32-S3 WROOM
- Arduino framework
