# ESP32 — Superloop

Проєкт демонструє неблокуючу роботу трьох LED та polling кнопки в одному
superloop. `delay()` не використовується.

| Компонент | GPIO | Підключення |
| --- | --- | --- |
| Червоний LED | 15 | GPIO → 220 Ом → LED → GND |
| Зелений LED | 16 | GPIO → 220 Ом → LED → GND |
| Синій LED | 17 | GPIO → 220 Ом → LED → GND |
| Кнопка | 21 | GPIO → кнопка → GND (`INPUT_PULLUP`) |

LED перемикаються незалежно кожні `250`, `500` і `1000` мс. Натискання
кнопки зупиняє всі LED, повторне натискання запускає їх знову. Debounce —
`30` мс.

Кожен прохід `Application::loop()` оновлює `Clock`, опитує кнопку та оновлює
три LED. Усі методи швидко повертають керування. Очікування реалізоване
порівнянням часу в незалежних екземплярах `IntervalTimer`.
