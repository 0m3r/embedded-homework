# Урок 11 — Модуль 2.3: Superloop

Два варіанти неблокуючого superloop:

- [`esp32`](esp32) — три LED, кнопка та debounce на ESP32/Arduino;
- [`stm32`](stm32) — вбудований active-low LED `PC13` на STM32F411/HAL.

Обидва варіанти працюють без `delay()` і `HAL_Delay()`. Компоненти перевіряють
час і швидко повертають керування в головний цикл.
