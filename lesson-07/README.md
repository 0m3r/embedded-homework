# Урок 07 — Модуль 1.7

## Керування реле за освітленістю

ESP32-S3 зчитує значення фоторезистора через ADC та автоматично керує
реле. Два окремі пороги утворюють гістерезис і запобігають частому
перемиканню реле біля одного граничного значення.

- [`src/main.cpp`](src/main.cpp) — мій варіант;
- [`teacher-solution/src/main.cpp`](teacher-solution/src/main.cpp) — варіант викладача.

### Логіка роботи

- `ADC < 1500` — реле вмикається;
- `ADC > 2500` — реле вимикається;
- `ADC` від `1500` до `2500` — попередній стан зберігається;
- стан виводиться в Serial Monitor кожні 500 мс.

### Підключення

| Компонент | GPIO |
| --- | ---: |
| LDR | 2 |
| Relay | 15 |

У варіанті викладача реле підключене до GPIO 17.

### Порівняння реалізацій

| Можливість | Мій варіант | Варіант викладача |
| --- | --- | --- |
| Пороги гістерезису | 1500 / 2500 | 1800 / 2200 |
| GPIO реле | 15 | 17 |
| Фільтрація ADC | Немає | Ковзне середнє з 8 значень |
| Підтвердження зміни | Одразу | Умова має триматися 500 мс |
| Опитування ADC | Блокуючий `delay(500)` | Неблокуюче, кожні 20 мс |
| Serial Monitor | ADC і стан реле | Raw, average, стан і pending |
| Налаштування ADC | Роздільність 12 біт | Роздільність 12 біт та attenuation 11 dB |

Обидва варіанти використовують гістерезис. Варіант викладача додатково
пригнічує шум ковзним середнім і часовим підтвердженням, тому реле
стійкіше до коротких змін освітлення.

### Збірка

```bash
pio run
```

Збірка варіанта викладача:

```bash
pio run --project-dir teacher-solution
```

Плата: Freenove ESP32-S3 WROOM, Arduino framework.
