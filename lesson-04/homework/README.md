# Домашнє завдання — два LED та дві кнопки

Проєкт демонструє режими `OUTPUT` та `INPUT_PULLUP`. Зовнішня кнопка вмикає швидке синхронне блимання, кнопка BOOT — повільне почергове блимання. Вибраний режим зберігається до натискання іншої кнопки.

## Підключення

| Компонент | GPIO | Підключення |
| --- | --- | --- |
| Перший LED | 15 | Анод через резистор 220 Ом до GPIO 15, катод до GND |
| Другий LED | 16 | Анод через резистор 220 Ом до GPIO 16, катод до GND |
| Зовнішня кнопка | 21 | Один контакт до GPIO 21, другий до GND |
| BOOT | 0 | Вбудована кнопка плати |

Обидві кнопки використовують внутрішню підтяжку `INPUT_PULLUP`, тому натиснутий стан відповідає `LOW`.

> GPIO 0 — strapping-пін. Натискання BOOT під час запуску або скидання переводить ESP32-S3 у режим прошивки.

## Режими

1. **Швидкий синхронний** — режим за замовчуванням. Обидва LED одночасно вмикаються та вимикаються із затримкою 200 мс. Активується зовнішньою кнопкою.
2. **Повільний почерговий** — один LED світиться, поки другий вимкнений; стани міняються кожні 1000 мс. Активується кнопкою BOOT.

Стан режиму зберігається у змінній `activeMode` протягом роботи програми. Після перезапуску знову вибирається швидкий синхронний режим.
