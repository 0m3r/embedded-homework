# Поліцейська мигалка

Проєкт керує червоним і синім світлодіодами та імітує поліцейську мигалку. Після чотирьох червоно-синіх циклів обидва світлодіоди разом передають сигнал SOS (`··· --- ···`). Послідовність повторюється безперервно.

## Підключення

| Компонент | GPIO | Підключення |
| --- | --- | --- |
| Червоний LED | 15 | Анод через резистор до GPIO 15, катод до GND |
| Синій LED | 40 | Анод через резистор до GPIO 40, катод до GND |

Кожен світлодіод повинен мати окремий струмообмежувальний резистор.

## Патерн

1. Червоний і синій LED по черзі роблять чотири короткі спалахи.
2. Обидва LED одночасно передають SOS кодом Морзе.
3. Крапка триває 180 мс, тире — 540 мс.
4. Цикл повторюється.

## Збірка та прошивка

```bash
pio run
pio run --target upload
```
