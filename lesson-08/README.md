# Урок 08 — Модуль 1.8

## Гнучкий слот. Поглиблене дослідження теми

Мініпроєкт об'єднує матеріал попередніх уроків: роботу з GPIO та ADC,
обробку кнопки, фільтрацію показань фоторезистора й керування світлодіодом.

### Реалізовано

- окремі класи `Button`, `Ldr` і `Led`;
- неблокуюче періодичне опитування через `millis()`;
- визначення довгого натискання кнопки (понад 1 секунду);
- фільтр ковзного середнього для ADC;
- увімкнення LED, коли кнопку утримано, а рівень освітлення нижчий за поріг;
- Task Watchdog Timer з тайм-аутом 5 секунд;
- виведення діагностичних даних і причини перезапуску в Serial Monitor;
- припинення опитування LDR після п'яти нульових відфільтрованих показань.

### Підключення

| Компонент | GPIO |
| --- | ---: |
| LED | 16 |
| LDR | 2 |
| Кнопка | 18 |

Налаштування GPIO, періодів опитування та порогу освітлення розміщені у
[`include/config.h`](include/config.h).

### Збірка

```bash
pio run
```

Плата: Freenove ESP32-S3 WROOM, Arduino framework.
